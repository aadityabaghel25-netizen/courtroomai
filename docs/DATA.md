# Data

No dataset or vector file is committed (`.gitignore`: `data/chroma_db/`, `data/raw/`, `data/judgments/`).

| Path | What | How it is made |
|---|---|---|
| `data/raw/*.json` | Indian Kanoon judgments (API JSON, HTML text) + bare-act snippets; `_fetch_log_*.json` records what each fetch added | `python -m ingestion.kanoon_fetcher` (needs `INDIANKANOON_API_TOKEN`) |
| `data/chroma_db/` | Chroma collection `courtroom_judgments`, `BAAI/bge-base-en-v1.5` (current counts in the README) | `python -m ingestion.embedder` (chunks `data/raw` then embeds) |
| `data/judgments/judgments.jsonl` | Full judgment text by case ID (HTML stripped, normalised), court, date, equivalent citations | `python scripts/build_judgments.py` |
| `data/statutes/acts/*.json` | Full texts of BNS, BNSS, BSA, IPC, CrPC, Indian Evidence Act (Indian Kanoon API, one call each) | `python scripts/fetch_acts.py` |
| `data/statutes/sections.jsonl`, `ik_crossref.csv` | The Acts split into sections; Indian Kanoon's "[Similar to Section X from Old …]" notes | `python scripts/fetch_acts.py --no-download` |
| `data/statutes/ipc_bns_map.csv` | Mapping table, columns `old_act,old_section,new_act,new_section,title,source,ik_agrees` | `python scripts/build_statute_map.py comparison_summary_BNS_to_IPC.pdf` (IPC→BNS from the official CAPT Bhopal table, each row with its page; CrPC→BNSS and Evidence Act→BSA from the Indian Kanoon notes). Never generated by a model. |

## Sources and licences

- Official IPC→BNS table: https://www.keralaprisons.gov.in/userfiles/act-and-rules/comparison_summary_BNS_to_IPC.pdf (CAPT Bhopal).
- Judgments: Indian Kanoon API (https://api.indiankanoon.org/). **The project owner must confirm Indian Kanoon's terms of use allow this reuse and display.** Each judgment links back to `https://indiankanoon.org/doc/<id>/`.
- Indian court judgments themselves are public documents; reporter citations shown are those Indian Kanoon lists as "Equivalent citations".
- Embedding model `BAAI/bge-base-en-v1.5` (MIT) and reranker `cross-encoder/ms-marco-MiniLM-L-6-v2` (Apache 2.0) are downloaded from Hugging Face at runtime.
